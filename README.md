# 🎬 Netflix Movie & TV Show Recommendation System

A content-based recommendation system that suggests similar movies and TV shows using Machine Learning.

## 🔍 Features
- TF-IDF based content similarity
- Cosine similarity for recommendations
- Interactive Streamlit web app
- Deployed on Streamlit Cloud & Hugging Face Spaces

## 🛠 Tech Stack
- Python
- Pandas, Scikit-learn
- Streamlit

## 🚀 How it Works
1. Text features extracted using TF-IDF
2. Similarity calculated using cosine similarity
3. Top similar movies and TV shows displayed
